# پروژه آغازین SurveyRTK

این پروژه یک نمونه اولیه اندروید است. برای ساخت APK نیازی به نصب Android Studio یا Android SDK روی رایانه شخصی نیست؛ می‌توان از GitHub Actions استفاده کرد.

## ساخت APK بدون Android Studio

1. در GitHub یک مخزن جدید و خالی بسازید (مثلاً `SurveyRTK`).
2. محتویات پوشه `SurveyRTK` را در ریشه مخزن بارگذاری کنید؛ پوشه مخفی `.github` نیز باید بارگذاری شود.
3. در GitHub وارد زبانه **Actions** شوید.
4. گردش‌کار **Build Android APK** را انتخاب کنید و **Run workflow** را بزنید؛ یا با push کردن فایل‌ها، ساخت خودکار شروع می‌شود.
5. پس از پایان موفق، وارد اجرای مربوطه شوید و از بخش **Artifacts** فایل `SurveyRTK-debug-apk` را دانلود کنید.
6. فایل ZIP دانلودشده را باز کنید و `app-debug.apk` را به گوشی منتقل و نصب کنید. ممکن است لازم باشد اجازه نصب از این منبع را در اندروید فعال کنید.

## نکته فنی
این خروجی فقط APK آزمایشیِ نسخه فعلی است. این نمونه هنوز نرم‌افزار کامل نقشه‌برداری و تضمین‌کننده دقت ۵ سانتی‌متر نیست. برای آن، توسعه و آزمایش اتصال گیرنده GNSS/RTK و دریافت تصحیحات لازم است. دقت ۵ سانتی‌متر فقط با گیرنده و شرایط مناسب RTK قابل دستیابی است؛ GPS داخلی گوشی به‌تنهایی چنین دقتی را تضمین نمی‌کند.
